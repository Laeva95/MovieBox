# 🎬<a href="http://3.34.63.9:8080/MovieBox/Index.jsp" target="_blank">MovieBox</a>

**영화 탐색부터 좌석 선택, 예매 관리까지 경험할 수 있는 영화 예매 웹 서비스**

MovieBox는 웹 개발 교육 과정에서 진행한 **5인 팀 프로젝트**입니다. Java 기반 웹 기술을 활용해 영화 정보를 조회하고, 좌석을 선택해 예매 내역을 관리할 수 있는 웹 서비스를 구현했습니다. 회원 기능과 영화·예매·리뷰 기능을 연동하며 Servlet/JSP 웹 애플리케이션의 구조와 팀 단위 기능 통합 과정을 익히는 데 중점을 두었습니다.

## 프로젝트 소개

- **프로젝트 유형:** 학원 개발 교육 과정 팀 프로젝트
- **팀 구성:** 5명
- **개발 환경:** Java, JSP/Servlet, MySQL, Apache Tomcat
- **주요 목표:** 회원·영화·예매 기능을 하나의 웹 서비스로 연결하고, 외부 API를 활용한 영화 정보 및 추천 기능 구현

## 주요 기능

### 회원

- 회원가입, 로그인, 로그아웃
- 회원 정보 조회 및 수정
- 비밀번호 해시 처리
- 이메일 인증을 통한 아이디 찾기 및 비밀번호 재설정
- 카카오 로그인 연동
- 마이페이지에서 예매 내역, 찜한 영화, 작성한 리뷰 확인

### 영화 탐색

- KMDb 영화 정보 API를 이용한 영화 데이터 조회 및 DB 저장
- 영화 목록 및 상세 정보 조회
- 검색어, 장르, 국가 등을 활용한 영화 탐색과 정렬
- 관심 영화를 찜 목록에 추가하거나 제거

### 예매

- 상영 일정 확인 및 좌석 선택
- 이미 예약된 좌석 확인
- 예매 정보 저장 및 예매 내역 조회
- 예매 취소
- 모바일 티켓 화면 제공

### 리뷰

- 리뷰 작성, 조회, 수정, 삭제
- 영화별 평점 및 리뷰 정보 확인
- 최신 리뷰 목록 제공

### 공지사항

- 공지사항 작성, 조회, 수정, 삭제
- 관리자 계정을 통한 공지사항 관리
- 특정 게시글 상단 고정 기능

### AI 영화 추천

- 사용자가 원하는 영화의 분위기나 조건을 입력하면 추천 요청을 처리
- DB에 등록된 영화 목록을 바탕으로 외부 AI API를 이용해 영화 추천 결과 제공
- OpenRouter API 사용

### 매점

- 매점 시스템을 통한 상품 구매
- 장바구니에 상품 담기

### 기술 스택
* **Backend**   : Java, JSP, Servlet  
* **Frontend**  : HTML, CSS, JavaScript, JSTL  
* **Database**  : MySQL, JDBC  
* **Server**    : Apache Tomcat 9 계열 환경  
* **데이터 연결** : JNDI DataSource  
* **외부 연동**  : KMDb 영화 정보 API, Kakao 로그인, SMTP 이메일 인증, OpenRouter AI API  
* **개발 도구**  : Eclipse 등 Java 웹 개발 IDE  

## 애플리케이션 구조

화면은 JSP, 요청 처리는 Servlet Controller, 데이터 접근은 DAO 중심으로 구성했습니다. 일부 기능은 Service 클래스를 두어 요청 처리와 비즈니스 로직을 분리했습니다.

```text
MovieBox
├── java/
│   ├── ai/          # AI 영화 추천
│   ├── booking/     # 상영 일정, 좌석, 예매 처리
│   ├── member/      # 회원, 로그인, 이메일 인증, 마이페이지
│   ├── movie/       # 영화 정보 조회 및 DAO
│   ├── notice/      # 공지사항 관련 기능
│   ├── review/      # 리뷰 관련 기능
│   └── store/       # 상품 관련 화면/클래스
│
└── webapp/
    ├── META-INF/    # Tomcat 리소스 설정
    ├── WEB-INF/     # 웹 애플리케이션 설정 및 라이브러리
    ├── ai/          # AI 추천 화면
    ├── inc/         # 공통 레이아웃
    ├── members/     # 회원 및 마이페이지 화면
    ├── movie/       # 영화 목록, 상세, 예매 화면
    ├── reservation/ # 예매, 결제 처리 화면, 모바일 티켓
    ├── review/      # 리뷰 화면
    ├── store/       # 상품 화면
    └── css/         # 스타일시트
```

## 실행 환경 및 설정

아래 항목은 개발 환경에 맞게 설정해야 합니다.

1. **필요 환경 준비**
   - JDK 21 이상
   - Apache Tomcat 9 계열
   - MySQL 8 계열
   - Eclipse 또는 Java 웹 애플리케이션을 실행할 수 있는 IDE

2. **데이터베이스 준비**
   - MySQL에 `moviebox` 데이터베이스를 생성합니다.
   - 프로젝트에서 사용하는 테이블을 생성하고 필요한 초기 데이터를 입력합니다.

3. **Tomcat 리소스 설정**
   - `webapp/META-INF/context.xml`에 로컬 DB 및 외부 연동 정보를 설정합니다.
   - 코드에서 사용하는 JNDI 리소스 이름은 다음과 같습니다.
     - `jdbc/moviebox`
     - `kakao/restApiKey`
     - `kakao/clientSecret`
     - `kakao/redirectUri`
     - `kmdb/serviceKey`
     - `OPENAI_API_KEY`
     - `email/smtpHost`
     - `email/smtpPort`
     - `email/smtpUsername`
     - `email/smtpPassword`
   - `context.xml.sample`은 DB 연결 예시를 위한 파일입니다. 실행에 필요한 외부 연동 설정은 프로젝트 코드에 맞게 추가해야 합니다.

4. **웹 애플리케이션 실행**
   - 프로젝트를 Eclipse의 Dynamic Web Project 등 적절한 Java 웹 프로젝트로 구성합니다.
   - Java 소스와 웹 리소스 경로를 프로젝트 설정에 맞게 지정한 후 Tomcat에 배포합니다.
   - 실행 URL 예시: `http://localhost:8080/MovieBox/Index.jsp` (Tomcat 포트 및 컨텍스트 경로에 따라 달라질 수 있습니다.)

5. **외부 서비스 설정**
   - KMDb API 키를 발급받아 설정합니다.
   - 카카오 로그인 사용 시 카카오 개발자 콘솔의 Redirect URI를 프로젝트 설정과 일치시킵니다.
   - 이메일 인증을 사용하려면 SMTP 서버 정보와 계정 정보를 설정합니다.
   - AI 추천 기능을 사용하려면 OpenRouter API 키를 설정합니다.
